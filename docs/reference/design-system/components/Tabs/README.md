# Tabs

An underlined row of uppercase labels that switches between views of the same thing.

**Consumer provides:** the tab labels (with counts in brackets where useful) and the selected tab.

- Labels in `button-label`, `content-muted`; the selected tab in `content` with a 2px `secondary-border` underline over a 1px `surface-border` rule.
- Gap 28px; scroll sideways on narrow screens.
- Use for record sections (Overview, Results…) and short pairs (Upcoming / Past). Don't use for filters (use FilterChips).
