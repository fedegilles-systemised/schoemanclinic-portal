# StatCard

A compact card with one headline number, used at the top of dashboards and for a marker at a glance.

**Consumer provides:** a label, the number (and unit), one line of context, and optionally a status pill and sparkline.

- Number in `big-number` with tabular figures; label in `eyebrow`; context in `small`.
- Colour the number `status-danger` only when it counts something that needs action.
- Rows of four on desktop, two on tablet, one on phones. Each stat links to the list it counts.
- Don't use stat cards for figures that are not the point of the screen.
